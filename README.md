# 魔兽世界：无限 · 全职业笔记

《魔兽世界：无限》1–60 级全职业练级笔记，纯静态站（无后端、无外部库、无构建）。根目录是职业入口页，每个职业一个独立目录，互不影响。

## 目录结构

```
index.html          职业入口页
hunter/             兽王猎笔记（宏命令 / 练级指南 / 天赋模拟）
paladin/            亡灵圣骑士笔记（练级指南 / 宏命令 / 天赋模拟）
warrior/            武器战笔记（练级指南 / 宏命令 / 天赋模拟）
assets/             根页面资源
sitemap.xml         全站站点地图
robots.txt
.github/workflows/  GitHub Pages 自动部署
```

每个职业目录自带 `index.html` 与 `assets/`（天赋图标等），页面自包含，可单独拷走使用。

## 本地运行

直接用浏览器打开根目录 `index.html`，从入口页点进各职业即可；也可单独打开 `hunter/index.html`、`paladin/index.html` 或 `warrior/index.html`。无需联网。

## 部署

仓库自带 `.github/workflows/deploy-pages.yml`：推送到 `main` 后由 GitHub Actions 发布，仓库 **Settings → Pages** 的 Source 保持 GitHub Actions。

线上地址：`https://nose996.github.io/wow-class-notes/`

## 口径与免责

各职业页的技能等级、天赋列位按《魔兽世界：无限》客户端数据整理；宏为对应版本的通用写法；路线、掉落与数值标注「待核」的地方以游戏内实测为准。天赋图标取自公开数据库的客户端同源图标。
